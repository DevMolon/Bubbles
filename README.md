# Bubbles 🫧

Jogo digital inspirado no clássico Tic-Tac-Toe (Jogo da Velha), desenvolvido como projeto acadêmico do curso de Engenharia de Software.

## Tecnologias

- Java
- Spring Boot
- HTML5
- CSS3
- JavaScript
- SQLite
- Maven

## Estrutura

- `codigo-fonte/` — Código-fonte da aplicação.
- `docs/` — Documentação e diagramas do projeto.

## Execução

Consulte as instruções de configuração e execução do projeto na documentação (docs, em "download da solução"), terá um arquivo .pdf chamado de: "instruções".

## Contexto

Projeto Integrador Transdisciplinar II (PIT II).

Universidade Cruzeiro do Sul Virtual.
